I’m building **ReviewSignal AI**, a Python-based platform that evaluates the reliability of code-review methods.

Rather than only generating AI code reviews, the project compares reviewer findings against a small, controlled dataset and reports metrics such as precision, recall, and false positives.

**Tech stack:** Python, FastAPI, SQLite, Ruff, Bandit, React, TypeScript, pytest.

My focus is on reproducible experiments, transparent evaluation logic, API design, and safe handling of source code. The current benchmark is intentionally small, so I’m treating the results as an engineering demonstration—not as a claim about the accuracy of AI code review in general.
